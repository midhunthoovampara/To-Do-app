A simple, elegant, and user-friendly To-Do List web app built using HTML, CSS, and JavaScript. This application helps users manage daily tasks efficiently with a clean UI and persistent storage using LocalStorage.

🚀 Features

➕ Add new tasks easily
✅ Mark tasks as completed
❌ Delete tasks with a single click
💾 Persistent data storage using browser LocalStorage
🎨 Modern and responsive UI design
⚡ Fast and lightweight (no frameworks)

🛠️ Tech Stack

HTML5 – Structure
CSS3 – Styling & layout
JavaScript (ES6) – Functionality & DOM manipulation
LocalStorage API – Data persistence
